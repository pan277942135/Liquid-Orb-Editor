## 2. 三态与本专项范围

- S1_IDLE：稳定静息，仍有极轻微呼吸。
- S1→S2_WAKE：0–350ms 水核、焦散、水滴、草叶受光苏醒；S1→S2 的光丝透明度转换并行于 0–450ms。
- S2_ACTIVE：持续呼吸与水滴/水草/阳光循环；不重置相位。
- S2_RELEASE/RETURN：350–950ms，**Orb 局部五条 R06 游丝舒展再回收**；690ms 开始 260ms C1 方向转换；不是识别全局第 10 阶段鱼体→Orb 回馈。
- S3_GLYPH：属于后续专项，不在本次实现。

**本次不包含**：照片外围大范围水光、寻鱼路径、真实 Mask、金光、Result Orb-to-Glyph、字幕/名称揭晓。ORB_RELEASE 应保留后续照片外围能量交接接口，但不能擅自画远距离水光射线。

### 4.1 每组冻结运动

| 路径 | 所在层 | 根部 UV | 叶尖 UV | 周期 | 相位 | 叶尖最大运动 |
|---|---|---|---|---:|---:|---:|
| BACK_B1 | BACK | (0.689793,0.527113) | (0.602073,0.259968) | 6200ms | 0° | ±0.018D |
| BACK_B2 | BACK | (0.650718,0.757576) | (0.747209,0.384370) | 6200ms | 100° | ±0.018D |
| FRONT_F1 | FRONT | (0.401914,0.749601) | (0.164274,0.396332) | 4800ms | 120° | ±0.030D |
| FRONT_F2 | FRONT | (0.491228,0.775917) | (0.208931,0.573365) | 4800ms | 240° | ±0.027D |

- 运动沿各自 Bezier 切线的法向局部偏移，不做刚性整片旋转。
- 根部：BACK 0D 固定；FRONT 根部位移 ≤0.003D。
- 运动包络 `smoothstep(0.10,1.0,s)^1.6`；s 为沿叶片中线的归一化弧长。
- `bend = amplitudeD × envelope × sin(2πt/T + phase)`；t 由唯一场景时钟 `sceneElapsedMs` 驱动。
- **避免影子重影：** 必须在原始 Core 的单次纹理取样中按 Mask 做局部 UV 位移：`mix(sampleOriginal(uv),sampleOriginal(uv−bendVector),maskAlpha)`；禁止先绘制静态 Core 再叠加一张同样叶子的移动 PNG。
- 前景/后景 Depth 顺序必须匹配 JSON；不能在玻璃最外面直接贴绿色卡通叶子。
- 阳光响应：`#A9D9C5` 局部漫反射 Alpha ≤0.10，叶尖闪光 Alpha ≤0.12，且只在 Mask 内；自然主光源位置保持不变。
- `R01_grass_back.svg` 和 `R01_grass_front.svg` 是已撤销旧资源，仍禁止集成。

### 4.2 Source → Runtime 映射门禁

原母版 1254×1254，现有 Android Runtime WebP 为 384×384。二进制/裁切内框不应靠猜测。Work 必须核实两者的源图纹理坐标对应关系，并记录 `sourceUV -> runtimeCoreUV` 的变换矩阵或等价数据。若 WebP 是与 PNG 不同的 crop，必须只调整 Mask 采样映射，而不是覆盖母版。

Android 16 优先在既有 Orb Core Render Host 内用局部 GPU Shader/UV Warp 实现；不新增 GLSurfaceView 或 EGL 宿主。低版本如无安全的位移路径，允许降级为母版水草 + Mask 内受光动态，但必须明确标为降级，不能声称已实现叶尖位移。

## 5. 关键帧与时序

| 时间 | 画面 | 值 |
|---|---|---|
| 0ms | S1 静息起点 | 母版保持可见；额外光晕 0；R06 游丝低能隐藏 |
| 80ms | 光学点亮 | 局部内部水光响应开始；Wake 曲线进度约 22% |
| 220ms | 水核苏醒 | 水滴焦散、草叶受光进入可辨认态；约 72% |
| 350ms | ORB_WAKE 完成并派发 RELEASE | Wake=100%；球体仍完整；释放开始 |
| 450ms | S1→S2 光丝 Alpha 过渡结束 | 五条游丝可辨认，主光源仍位于左上 |
| 690ms | S2 局部 R06 RETURN 启动 | 保留弧长位置，C1 260ms 速度渐变 |
| 950ms | 回到 S2 持续游动 | 不是全局第十阶段 Orb Return |

苏醒局部 Easing：`cubicBezier(0.16,1.0,0.30,1.0)`。S1→S2 光丝 Alpha Easing：`smoothstep`。900ms 入口和 700ms 照片归位仍并行，不叠加出额外入口时长。
